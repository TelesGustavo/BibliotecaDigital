# Biblioteca Digital UniFECAF

Projeto acadêmico desenvolvido para a disciplina de **Design Web**. O site apresenta uma proposta de biblioteca digital com informações sobre o acervo, as unidades e os canais de contato.

## Acesse o site

[Visitar a Biblioteca Digital UniFECAF](https://telesgustavo.github.io/BibliotecaDigital/)

- **Instituição:** UniFECAF
- **Curso:** Análise e Desenvolvimento de Sistemas
- **Disciplina:** Design Web
- **Professor(a):** Felipe Bonatto

## Recursos do site

- Navegação por seções da biblioteca
- Apresentação das unidades com imagem e informações de contato
- Layout adaptável para computadores e celulares
- Estruturação semântica e recursos de acessibilidade

## Tecnologias

- HTML5
- CSS3
- GitHub Pages para publicação

